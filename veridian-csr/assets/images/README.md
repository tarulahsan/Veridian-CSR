# Demo Images for Veridian CSR

This directory is intended to hold demo images such as logos, backgrounds, and illustrative graphics for the Veridian CSR theme.

**Important Note on Optimization:**

The image files currently in this directory (if any, beyond this README) might be placeholders. For the final product and to meet performance targets (like a Google PageSpeed Insights score of 90+), all demo images **must** be:

1.  **Optimized:** Images should be compressed to reduce file size without significant loss of visual quality.
2.  **Formatted as WebP:** Where appropriate, use the WebP format for its superior compression and quality characteristics compared to older formats like JPEG and PNG. Provide fallbacks if necessary for older browser compatibility, though WebP is widely supported.
3.  **Appropriately Sized:** Images should be served at the dimensions they are displayed to avoid unnecessary scaling by the browser.

This optimization is crucial for fast loading times and a good user experience. Tools like Squoosh, ImageOptim, or various command-line utilities (e.g., `cwebp`) can be used for this purpose.
