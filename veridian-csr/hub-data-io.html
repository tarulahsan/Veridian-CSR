Data Import/Export Hub

Manage your application data using Excel or CSV files.

Import Data

Import your entire dataset from an Excel (.xlsx) or CSV (.csv) file. This will overwrite existing data in the browser.

Drag & drop your file here, or click to select file.

Validation Issues:
    Data imported successfully!
    Export Data

    Export your entire current application dataset. This includes all entered metrics, checklist states, and configurations.

    The CSV export might be a simplified version of your data, suitable for quick checks or use in other systems. For a full backup, Excel is recommended.

    Data Management Note:

    All data is stored locally in your browser's localStorage. The import/export functionality (using SheetJS) allows you to back up, transfer, or work with your data offline.

    Imported data should be a single JSON object that was previously exported from this application or follows the exact same structure. The application will attempt to parse and validate the structure.
